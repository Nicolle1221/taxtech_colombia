# REGLAS DE OPTIMIZACIÓN DE TOKENS PARA CLAUDE CODE
1. Modificaciones Incrementales: Está prohibido reescribir un archivo completo si solo se requiere modificar una función. Usa bloques de edición precisos.
2. Cero Comentarios de Relleno: Elimina explicaciones textuales largas en la consola. Solo imprime logs de éxito o errores de código.
3. Validación Local Previa: Antes de proponer un cambio, ejecuta de forma autónoma los comandos en la Mac M2.
4. Cómputo Determinista: No intentes resolver matemáticas fiscales mediante lenguaje natural; delega todo cálculo a funciones puras.
